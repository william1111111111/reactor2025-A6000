# CoReSet supplementary experiments

- [English Markdown appendix](CoReSet_Appendix_Experiments_EN.md)
- [中文实验结果整理](CoReSet_附录实验结果_中文.md)
- [Source-file hashes and provenance](source_manifest.json)

The two Markdown versions contain the same 21 result tables and six figure groups. The `figures/` directory provides both PNG and PDF assets; figure links work relative to each document.

The appendix covers the matched reference-selection/assignment 2×2 study, three-seed A0/A1 distillation results, set-structure preservation and reference coverage, the uncentered A3 control, balanced optimal transport, inference efficiency, training-view diagnostics, and qualitative visualizations. All quantitative studies here use REACT2025; the four-cell study has one training seed per cell, whereas the fixed-teacher A0/A1 study uses three student seeds.

The reported metric trade-offs and statistical limitations are retained. The source manifest records hashes and original local provenance paths; datasets, checkpoints, and per-context prediction caches are not part of this appendix export.
